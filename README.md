# OZHIVAET — Волшебная библиотека (демо Mini App)

Мобильный статический интерфейс для Telegram Mini App. Три тарифа: 299/599/999 ₽. Выбор мира, имя/возраст, просмотр заказа и копирование текста для отправки в Telegram.

## Что уже работает
- Адаптивный дизайн с персонажем Люми
- Выбор тарифа и сказочного мира
- Локальный ввод имени, возраста и пожеланий
- Проверка заполнения, итог заказа, копирование текста
- Кнопка перехода к исполнителю в Telegram

## Чего пока нет
- Автоматической отправки заказов, серверной части и базы данных
- Приёма оплаты и автоматической генерации сказок
- Загрузки/передачи фотографий ребёнка (намеренно не реализовано в демо)

## Бесплатная публикация
1. Разместите файлы `index.html` и `lumi.png` на статическом HTTPS-хостинге (например, Cloudflare Pages).
2. Проверьте сайт на телефоне.
3. В @BotFather выберите @OzhivaetMagicBookBot и настройте Menu Button / Web App URL на опубликованный HTTPS-адрес.
4. Для автоматического приёма заказов потребуется отдельный защищённый серверный обработчик Telegram и управление данными. Не передавайте токен бота в HTML/JavaScript.

ВНИМАНИЕ: это демонстрационная витрина. Не обещайте автоматическую выдачу книг до реализации серверной части.
